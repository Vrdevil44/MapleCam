# MapleCam Sentinel

A Canadian dashcam product concept — development plan, configuration, and a working PWA prototype ("MapleCam Sentinel").

## What's here

- `Canadian Dashcam Product Development Plan.md` — the full product plan: market, features, roadmap
- `index.html` + `static/` + `src/` — the Sentinel PWA prototype
- `config.yaml` — device configuration
- `scripts/` — build/utility scripts

## Run it

Open `index.html` in a browser, or serve the directory with any static server:

```bash
npx serve .
```

## Status

Concept/prototype stage. The PWA demonstrates the core UX; hardware integration is out of scope.
